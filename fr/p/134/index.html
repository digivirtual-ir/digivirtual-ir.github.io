Description

Ce pack de modèles de passeport Russie réunit deux versions complètes en une seule publication : le passeport de nouvelle génération de la Fédération de Russie (V3) et le passeport à l'ancien format (V2), tous deux sous forme de fichiers PSD entièrement modifiables. Le fichier V3 mesure 1275×1750 px tandis que le V2 mesure 1650×2154 px ; tous les textes se trouvent sur des calques de texte séparés, les photos sont insérées via des objets intelligents et toutes les polices utilisées sont fournies.
