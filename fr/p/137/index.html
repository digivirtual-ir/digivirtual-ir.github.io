Description

Ce modèle de permis de conduire thaïlandais reproduit la carte „Private Motorcycle Driving Licence (Temporary)“ du Royaume de Thaïlande sous forme de fichier PSD stratifié de 2480×3425 px. Le recto et le verso sont conservés dans deux groupes distincts, et chaque libellé, nom et date se trouve sur un véritable calque de texte Photoshop, ce qui permet de remplacer toutes les données provisoires sans altérer le design d’origine de la carte.

Éléments authentiques contenus dans ce fichier

  1. En-tête du recto : le drapeau thaïlandais et l’emblème royal Garuda avec les lignes „ประเทศไทย / Kingdom of Thailand“ et „ใบอนุญาตขับรถยานยนต์ส่วนบุคคล / Private Motorcycle Driving Licence (Temporary)“
  2. Champs bilingues du recto : „No. 00000000“, „วันออกบัตร / Issue Date 0 January 0000“, „วันสิ้นอายุ / Expiry Date“ ainsi que les mois thaïlandais มกราคม et เมษายน
  3. Bloc nom : „ชื่อ / Name“ avec le nom provisoire JOHN CITIZEN WILLIAMS et un cadre photo prêt à être remplacé
  4. Ligne d’identité : „เลขประจำตัวประชาชน / ID No. A0000000“ et „วันเกิด / Birth Date 0 April 0000“
  5. Le bandeau bleu inférieur : „นายทะเบียนจังหวัด ภูเก็ต“ — Registrar provincial de Phuket avec un motif circulaire décoratif
  6. Verso : numéro de permis „00 00 0000 0000“, bande magnétique noire, code QR et icône de motocyclette
  7. Bloc adresse : „ที่อยู่ / Address“ avec le texte 000/00 Karon, Muang Phuket, Phuket et la version thaïlandaise โคกโตนด ต.กะรน อ.เมือง จ.ภูเก็ต
  8. Champ de signature : la signature (กานดา สันติภัทรานนท์) au-dessus de „นายทะเบียน / Authority“

Le lien de téléchargement est activé dans votre compte immédiatement après l’achat. Le fichier est livré sous forme d’archive ZIP sans mot de passe et contient le PSD stratifié (2480×3425 px) ainsi qu’un dossier de polices avec Arial (normale et grasse) et Tahoma.
