Description

Ce modèle de passeport hongrois au format PSD reproduit la page de données personnelles du «ÚTLEVÉL» hongrois — le passeport MAGYARORSZÁG — en qualité d’impression 2544×2584 px au format Photoshop (PSD). Tous les textes sont des objets texte modifiables sur des calques nommés, de sorte que chaque champ peut être personnalisé dans Photoshop ou sur photopea.com sans altérer la mise en page d’origine.

Détails authentiques de ce modèle

  1. Page de données personnelles complète avec l’en-tête MAGYARORSZÁG / ÚTLEVÉL PASSPORT, le fond guilloche et le numéro de document perforé au laser
  2. Ligne type/code : Type P, Code HUN, numéro de passeport BD4237509
  3. Bloc du nom du titulaire : Nom « PSD », Prénoms « TEMPLATES », nationalité MAGYAR/HUNGARIAN
  4. Date de naissance 16 DEC/DEC 2000, sexe F/M, lieu de naissance BUDAPEST
  5. Date de délivrance 14 JAN/JAN 19, date d’expiration 14 JAN/JAN 29, autorité de délivrance KEK KH, signature manuscrite du titulaire
  6. MRZ à deux lignes en OCR-B : P<HUNTPSD<<TEMPLATES... / BD42375094HUN0012167M2901149...02
  7. Calque photo objet intelligent et tous les champs modifiables ; polices incluses : OCR-B et la famille OpenSans (5 fichiers TTF)
  8. Mode d’emploi : ouvrez dans Photoshop ou sur photopea.com, double-cliquez sur l’objet intelligent pour importer la photo, modifiez le calque souhaité puis exportez
