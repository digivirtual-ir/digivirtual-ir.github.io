Description

Le modèle PSD de la facture d'énergie UK Npower est un fichier Photoshop entièrement modifiable, fidèlement reconstruit à partir d'une véritable facture d'électricité npower. Le pack téléchargeable contient le modèle PSD de la facture ainsi que la police Trebuchet MS, nécessaire pour une édition précise des textes, dans le même fichier zip. Tous les éléments — logo, tableau de consommation, code-barres et QR code — sont sur des calques séparés.

Cette publication inclut trois fichiers : le PSD original V2 (le design de 2019 avec les données d'exemple de Martynas Porcikas — 45 Masefield Avenue London HA7 3LY — le compte 152871506 et le montant £308.02) en 2480x3510 avec les polices nécessaires dans le même zip, un PSD V1 (le design de 2018 avec les données d'exemple d'Adele Wood) avec la police Trebuchet MS dans le zip, et l'ancien PDF V1 (le design plus ancien de 2013 — un document de cinq pages avec les données d'exemple d'Elliott Sumerfield, le compte 133480244, le montant £120.41 et l'échéance 04-Dec-2013).
