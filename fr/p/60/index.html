Description

Le modèle de la facture d'électricité italienne d'Enel Energia (version 2) est fourni sous forme de fichier PSD Photoshop de haute qualité et entièrement modifiable, afin que vous puissiez le personnaliser facilement selon vos besoins. Le design reproduit fidèlement la facture officielle «ENEL SERVIZIO ELETTRICO — Servizio di Maggior Tutela» avec tous les détails du document. Le paquet comprend 3 fichiers PSD ; tous les calques sont organisés et nommés, ce qui rend la modification des textes, numéros, dates et montants très simple.

Quelles informations trouverez-vous dans ce fichier ?

  1. En-tête officiel Enel avec le logo et le slogan «L'ENERGIA CHE TI ASCOLTA» ainsi que le titre ENEL SERVIZIO ELETTRICO — Servizio di Maggior Tutela
  2. Section DATI CLIENTE avec le numéro client (exemple 748 000 111), le code fiscal Codice Fiscale (exemple BNCRST81A01H501D) et les coordonnées du client avec l'adresse romaine
  3. Encadré de paiement BOLLETTA PER LA FORNITURA DI ENERGIA ELETTRICA avec le numéro de facture (exemple 4702736303844), la date d'émission 29/07/2019, la période de facturation mai–juillet 2019 et un montant de 150,08 € à régler avant le 09/08/2019
  4. Mention de prélèvement automatique via le compte bancaire (SANPAOLO BANCO DI NAPOLI S.P.A.) et le code-barres latéral
  5. Section DATI FORNITURA avec le code POD (exemple IT001E74800011), le numéro de raccordement 4701239303824, le tarif D2, l'alimentation monophasée 230 V, le compteur électronique multi-tarifs (EF) et une puissance contractuelle de 3 kW
  6. Tableau RIEPILOGO IMPORTI FATTURATI avec le détail des montants : périodes antérieures 77,39 ; services de vente 20,73 ; services de réseau 23,25 ; taxes 15,07 ; total énergie et taxes 136,44 € plus TVA 10 %
