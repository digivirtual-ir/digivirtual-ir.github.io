Description

Ce pack ancien des modèles de permis de conduire britannique comprend 3 modèles PSD Photoshop entièrement modifiables — Ancienne version V1, Ancienne version V2 et le permis Provisional — le tout dans un seul produit. Il est conçu pour les projets qui nécessitent les anciens designs du permis britannique.

Ce que vous trouverez dans cet ancien pack

  1. Fichier PSD de l'ancienne version V1 du permis britannique
  2. Fichier PSD de l'ancienne version V2 du permis britannique
  3. Fichier PSD du permis Provisional britannique
  4. Un dossier de polices avec les typographies utilisées dans les versions
  5. Tous les champs personnels modifiables — nom, prénoms, date de naissance, numéro de permis, adresse, catégories de véhicules, dates de validité, photo et signature
  6. Prêt pour l'export photo haute résolution ou l'impression directe
  7. Fonctionne dans Photoshop ainsi que dans l'éditeur web gratuit Photopea

Les liens de téléchargement des 3 versions sont activés dans votre compte dès l'achat, pour démarrer sans attendre. Cet ancien pack convient aux mock-ups, aux supports de formation, aux reconstitutions d'époque et à la production de contenu visuel.
