Description

Ce modèle de passeport de Dominica au format PSD reproduit le design du passeport du Commonwealth de la Dominique (un État insulaire des Caraïbes — pas la République dominicaine) sur une toile de 1299×1827 px. Tous les champs sont des calques de texte modifiables dans Photoshop et tout le nécessaire est fourni avec le pack.

Ce que vous trouverez dans ce modèle

  1. Fichier PSD entièrement modifiable reprenant le design du passeport de Dominica sur une toile de 1299×1827 px
  2. Tous les champs de la page de données sont modifiables — numéro de passeport A0000000, type P, code pays DMA, nom TEMPLATES, prénom ALL PSD
  3. Les champs nationalité DOMINICAN, lieu de délivrance ROSEAU et lieu de naissance EGYPT sont prêts à être modifiés, ainsi que les champs de date
  4. Les deux lignes MRZ du bas sont entièrement modifiables
  5. Remplacement de la photo via des calques d'objet intelligent — le portrait principal et la photo secondaire image-dans-l'image
  6. Un calque de signature séparé pour un rendu réaliste
  7. Un calque de fond à pois et 5 polices incluses dont OCR-B et une police de signature manuscrite
  8. Fonctionne dans Photoshop et dans l'éditeur web gratuit Photopea
