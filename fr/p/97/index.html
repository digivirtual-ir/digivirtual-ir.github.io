Description

Le modèle PSD du passeport letton reproduit la page des données personnelles du document de voyage letton dans un fichier Photoshop entièrement calqué et prêt à imprimer. L'en-tête bilingue LATVIJA · LATVIA · LETTONIE surmonte le bloc de données type P, le numéro de passeport LV4017173, la nationalité LATVIJAS et tous les champs de texte du vrai livret. Le titulaire d'exemple DAVIS RACHEL figure avec la date de naissance 30.06.1992, le lieu de naissance RIGA et le numéro personnel 020490-10517, le tout placé sur des calques nommés pour une édition rapide et un export propre en PNG ou PDF.

Ce que reproduit le modèle

  1. En-tête LATVIJA · LATVIA · LETTONIE avec la mention trilingue PASĒ / PASSPORT / PASSEPORT
  2. Ligne type P avec le code de l'État émetteur LVA et le numéro de passeport LV4017173
  3. Nom DAVIS et prénom RACHEL dans les champs personnels numérotés
  4. Nationalité LATVIJAS avec le code d'identité personnel 020490-10517
  5. Date de naissance 30.06.1992, lieu de naissance RIGA et mention de sexe S/F
  6. Champ taille 178 à côté du code de l'État émetteur
  7. Date de délivrance 25.07.2021 avec l'autorité PMLP RIGAS 3.NODAĻA et expiration 24.07.2026
  8. Bloc MRZ TD3, zone de signature du titulaire, portrait fantôme et le graphisme de la grue rouge

Ouvrez le PSD dans Photoshop ou l'éditeur gratuit photopea.com, installez les polices OCR-B fournies, réécrivez les valeurs d'exemple, insérez le portrait de votre choix et exportez le format voulu. Le modèle convient aux maquettes d'interface, aux démonstrations de vérification d'identité, aux supports de formation KYC, aux portfolios de design et aux accessoires imprimés pour tournages. La page d'observations étant incluse avec les armoiries, une double page peut être composée pour des présentations style livret.
