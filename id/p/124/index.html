Deskripsi

Bundel templat SIM Hawaii USA ini mengumpulkan tiga file Photoshop berlapis dalam satu produk: edisi V3 baru (dengan artboard normal dan bergaya pindai), edisi V2, dan edisi cetak berformat besar. Setiap file mereproduksi kedua sisi Hawaii Driver License — depan dengan holo pelangi dan belakang dengan kode batang — termasuk grup layer „edit text here“, smart object foto dan semua font, sehingga setiap nilai dapat diedit di Adobe Photoshop atau Photopea tanpa meratakan layer.

Bidang autentik yang termuat dalam set ini

  1. Sisi depan kartu autentik: header Hawaii / DRIVER LICENSE / USA dengan kotak bendera negara bagian, gambar rangkaian pulau, latar gradien pelangi dan tanda AHCD / DONOR di kanan bawah
  2. Blok identitas V3: Last SAMPLE, First, M TINA, A, jalan 123 ANYSTREET, baris kota ANYCITY, AA 00000 dan nomor lisensi DL# H00000000
  3. Baris data V3: DOB 02/21/1984, Issue 02/17/2010, kedaluwarsa 02/21/2018, jenis kelamin M, tinggi 5-02, berat 120 dan warna mata BRO
  4. Kelas dan sisi belakang: 9. Class 3, 12. Restrictions A, 5a. Endorsements NONE, baris CORRECTIVE LENSES, kode batang 2D 12345678 dan paragraf GVWR tentang kendaraan penumpang, bus dan truk
  5. Area tanda tangan dengan layer tanda tangan tulisan tangan, artboard tanda tangan bergaya pindai dan folder Sign fonts berisi Historia, Halimun, Youthness dan Southampton
  6. Edisi V2 (1183×1183): DL# H98520214, nama RACHEL DAVIS, tanggal lahir 02/21/1991, kedaluwarsa 02/21/2024 dan empat varian latar yang dapat dipilih di grup SELECT BACKGROUND
  7. Edisi cetak (2025×1275): bidang bernomor 4a. Iss, 9. Cl, 12. Re, 16. Ht, 17. Wt dan 18. Eye dengan contoh LOW MICHELLE, JUO-MEI, alamat 3380 LIKINI ST, kedaluwarsa 07/21/2018 dan strip Aloha State yang berulang di sisi belakang
  8. Smart object foto (placeholder asia-man) di setiap file, layer teks native untuk semua nilai serta font edisi cetak arial, arial bold dan FG Rebecca Script dikemas dalam arsip

Tautan unduhan diaktifkan di akun Anda segera setelah pembelian: tiga file ZIP tanpa kata sandi, file PSD di akar setiap arsip. Bundel ini ideal untuk mockup UI, demo KYC dan materi edukasi tentang dokumen identitas Amerika Serikat.
