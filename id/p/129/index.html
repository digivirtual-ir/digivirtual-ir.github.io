Deskripsi

Templat Kartu Identitas Kamboja ini menggabungkan dua file Photoshop berlapis dalam satu produk: versi yang lebih baru V2 (file Cambodia-ID-V2.psd berukuran 1748×2480 piksel) dan versi sebelumnya V1 (file ID Card Khmer.psd berukuran 1500×1000 piksel). Setiap file membangun kembali bagian depan dan belakang kartu identitas Kamboja — dengan smart object foto, lapisan teks natif dan semua font, sehingga setiap nilai dapat diedit di Adobe Photoshop atau Photopea tanpa meratakan lapisan.

Bidang autentik yang termuat dalam bundel ini

  1. Kepala versi V2: sebutan KINGDOM OF CAMBODIA dengan bidang dwibahasa Khmer dan Inggris serta baris nomor kartu
  2. Baris MRZ versi V2: baris IDKHM0210742545<<<, baris 8203025M2411200KHM<<< dan nama pemegang KEUK<<NARIN
  3. Blok identitas versi V2: nama bahasa Inggris JOHN CITIZEN dengan tanggal lahir, jenis kelamin, tinggi, tempat lahir di provinsi Kandal, alamat dan tanda tangan J. Citizen
  4. Grup foto versi V2: smart object foto dengan lapisan Pic on Pic di dalam kanvas 1748×2480 piksel
  5. Font versi V2: Arial Regular, OCR-b_10__bt dan SCRIPTIN dikemas di dalam folder font
  6. Versi V1: nama PHILIP PUTMAN dengan nama Khmer, tanggal lahir 17.03.1988 dan smart object tanda tangan
  7. Versi V1 pada 1500×1000: bagian depan dan belakang kartu dengan elemen izin tinggal dan chip dalam tata letak
  8. Kedua versi: lapisan teks natif yang dapat diedit sepenuhnya di Adobe Photoshop dan Photopea tanpa menggabungkan lapisan

Tautan unduhan diaktifkan di akun Anda segera setelah pembelian dan Anda menerima dua file ZIP tanpa kata sandi dengan file PSD di akar setiap arsip. Bundel ini ideal untuk mockup verifikasi identitas, desain UI dan materi edukasi tentang dokumen identitas Kamboja.
