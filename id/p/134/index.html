Deskripsi

Paket templat paspor Rusia ini menyatukan dua versi lengkap dalam satu postingan: paspor generasi baru Federasi Rusia (V3) dan paspor format lama (V2), keduanya sebagai file PSD yang dapat diedit sepenuhnya. File V3 berukuran 1275×1750 px sedangkan file V2 berukuran 1650×2154 px; semua teks berada pada lapisan teks terpisah, foto disisipkan melalui smart object, dan semua font yang digunakan disertakan.

  3. Konstruksi file V3: foto utama dan ghost photo pada smart object terpisah, dua lapis tanda tangan hasil pindaian, elemen hologram (emblema РОССИЙСКАЯ ФЕДЕРАЦИЯ, bola dunia RUS), latar guilloche, dan lapis efek pindaian untuk hasil yang realistis
