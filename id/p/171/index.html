Deskripsi

Template paspor Uganda berformat PSD ini mereproduksi halaman data paspor Republik Uganda dalam satu file berukuran 1192×1644 piksel, lengkap dengan header «REPUBLIC OF UGANDA» dan label dwibahasa PASSPORT/PASSEPORT. Semua bidang merupakan lapisan teks asli yang dapat diedit di Adobe Photoshop, dan grup lapisan (latar belakang, foto, tanda tangan, teks) tertata rapi sehingga file siap digunakan sejak pembukaan pertama dan berfungsi sebagai properti identitas yang meyakinkan.

Bidang autentik yang termuat dalam file ini

  1. Header dan kode: «REPUBLIC OF UGANDA» dengan PASSPORT/PASSEPORT, tipe «PC» dan kode negara «UGA»
  2. Blok data pribadi: nama keluarga «TEMPLATES», nama depan «ALL PSD», kewarganegaraan «UGANDAN», nomor paspor «B1365188» dan nomor berkas «B1365113»
  3. Data inti: tanggal lahir «12 02 2000», jenis kelamin «M» dan profesi «BUSINESS»
  4. Data penerbitan: tanggal penerbitan «29 06 2021», tanggal kedaluwarsa «29 06 2031» dan otoritas penerbit «UGA GOVT KAMPALA»
  5. Blok foto: smart object MAIN PHOTO untuk potret utama dan lapisan GHOST PHOTO untuk gambar bayangan sekunder, keduanya dapat ditukar dalam hitungan detik
  6. Tanda tangan: lapisan tanda tangan terpisah yang mudah diedit atau diganti
  7. Baris pertama MRZ: «P<UGATEMPLATES<<ALL<PSD» dengan pengisi «<» hingga akhir pita
  8. Baris kedua MRZ: «B1365188<1UGA9101014M310629900766751» pada pita TD3 berisi 44 karakter
