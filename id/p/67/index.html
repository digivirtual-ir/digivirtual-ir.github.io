Deskripsi

Paket templat Paspor Filipina yang lengkap ini mencakup 2 templat PSD Photoshop yang sepenuhnya dapat diedit — edisi baru V3 dan V2 dwibahasa yang lebih lama — semuanya dalam satu produk. Setiap kolom dapat disesuaikan dalam hitungan detik dan semua font yang diperlukan disertakan dalam paket.

Apa yang akan Anda temukan di dalam paket ini

  1. File PSD versi V3 — desain terbaru paspor Filipina dengan tata letak modern
  2. File PSD versi V2 — desain dwibahasa sebelumnya (Filipina/Inggris); foto ditempatkan pada latar belakang biru
  3. Folder font berisi OCR-B untuk V3 dan font condensing yang digunakan V2
  4. Semua kolom pribadi dapat diedit — nomor paspor, nama keluarga, nama depan, kewarganegaraan, jenis kelamin, tanggal dan tempat lahir, tanggal terbit dan kedaluwarsa, otoritas penerbit, foto dan tanda tangan
  5. Dua baris MRZ di bagian bawah sepenuhnya dapat diedit
  6. Penggantian foto melalui lapisan smart object — tanpa merusak desain
  7. Berfungsi di Photoshop dan juga di editor web gratis Photopea

Tautan unduhan kedua versi diaktifkan di akun Anda segera setelah pembelian, sehingga Anda dapat mulai bekerja tanpa penundaan. Paket ini cocok untuk pekerjaan desain grafis, mockup, materi pelatihan, dan produksi konten visual.
