Deskripsi

Template PSD kartu izin tinggal Inggris ini adalah file Photoshop yang dapat diedit sepenuhnya dan mencakup kedua sisi kartu. Setiap kolom diedit melalui lapisan smart object dalam hitungan detik, slot foto pemegang diganti dengan sekali klik ganda, dan kelima font yang dibutuhkan disertakan dalam paket.

Kolom yang dapat diedit dalam template ini

  1. Satu file PSD berisi sisi depan dan belakang kartu izin tinggal, tata letak autentik, dan lapisan smart object untuk setiap teks
  2. Sisi depan: nomor dokumen RE2395698, nama pemegang, berlaku hingga 31-12-2024, serta tempat dan tanggal penerbitan UK 16-09-2019
  3. Kolom jenis izin dan baris keterangan NO TIME LIMIT — semua label dan nilai dapat diedit
  4. Slot foto pemegang dan tanda tangan tulisan tangan sebagai lapisan smart object; klik ganda, tempatkan file baru, lalu simpan
  5. Sisi belakang: tanggal dan tempat lahir 13-07-1982, jenis kelamin dan kewarganegaraan sebagai kolom terpisah yang dapat diedit
  6. Keterangan NO PUBLIC FUNDS di sisi belakang plus foto hantu semi transparan untuk salinan yang realistis
  7. Blok MRZ tiga baris di bagian bawah sisi belakang dengan nomor dokumen IRGBRRE23956982 pada baris pertama — setiap karakter dapat diedit
  8. Kelima font yang dibutuhkan termasuk OCR-B Inggris dan Myriad Pro; berfungsi di Photoshop dan editor web gratis Photopea
