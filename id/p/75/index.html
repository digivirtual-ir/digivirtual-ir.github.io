Deskripsi

Bundel lengkap template paspor Siprus ini mencakup 2 template PSD Photoshop yang sepenuhnya dapat diedit — edisi terbaru V2 dan yang lebih lama V1 — semuanya dalam satu produk. Setiap bidang dapat disesuaikan dalam hitungan detik dan semua font yang diperlukan disertakan dalam paket.

Apa yang akan Anda temukan di dalam bundel ini

  1. File PSD versi V2 — desain terbaru pada kanvas resolusi tinggi berukuran 3636×3434 px dengan halaman data trilingual (Yunani/Turki/Inggris)
  2. File PSD versi V1 — desain klasik sebelumnya dengan tata letak trilingual yang sama, lambang negara dan grup stempel, kanvas 1680×2263 px
  3. Folder font untuk V2 — 9 font termasuk OCR-B, font perforasi dan skrip tulisan tangan untuk tanda tangan; font yang sama juga cocok untuk file V1
  4. Semua bidang pribadi dapat diedit — nomor paspor K00233976, jenis P, kode negara CYP, nama keluarga LEE, nama depan STEVEN, tanggal lahir 11/02/1994, penerbitan 14/07/2015, kedaluwarsa 14/07/2025, tempat lahir LARNAKA, kewarganegaraan CYPRIOT
  5. Kedua baris MRZ di bagian bawah sepenuhnya dapat diedit
  6. Penggantian foto melalui lapisan smart-object — tanpa merusak desain
  7. Lapisan tanda tangan terpisah dan smart object khusus untuk foto sampul demi hasil yang realistis
  8. Bekerja di Photoshop dan juga di editor web gratis Photopea

Tautan unduhan kedua versi diaktifkan di akun Anda segera setelah pembelian, sehingga Anda bisa mulai bekerja tanpa penundaan. Bundel ini cocok untuk pekerjaan desain grafis, mockup, materi pelatihan dan produksi konten visual.
