Deskripsi

Bundel lengkap template Paspor Spanyol ini mencakup 2 template PSD Photoshop yang sepenuhnya dapat diedit — edisi modern V2 dan generasi sebelumnya V1 — semuanya dalam satu produk. Setiap kolom dapat disesuaikan dalam hitungan detik dan semua font yang diperlukan disertakan dalam paket.

Apa yang akan Anda temukan di dalam bundel ini

  1. File PSD versi V2 — desain paspor Spanyol generasi terbaru dengan tata letak modern dan data contoh Salvador DALI serta nomor dokumen ZAB000221
  2. File PSD versi V1 — desain generasi sebelumnya (model 2008 hingga 2013) dengan data contoh FOMKIN ALEKSEI, nomor dokumen BB109068, dan nomor identitas A2006018973
  3. Folder font berisi OCR-B, dotted-letters, dan font tanda tangan yang digunakan versi V2
  4. Semua kolom pribadi dapat diedit — nomor paspor, nama keluarga, nama depan, kewarganegaraan, jenis kelamin, tanggal dan tempat lahir, tanggal terbit dan kedaluwarsa, nomor dukungan A9999999900, foto, dan tanda tangan
  5. Dua baris MRZ di bagian bawah dokumen sepenuhnya dapat diedit
  6. Penggantian foto melalui lapisan smart object di versi V2 — tanpa merusak desain
  7. Lapisan hologram dan efek hasil pindai sudah disiapkan di versi V2
  8. Berfungsi di Photoshop dan juga di editor web gratis Photopea

Tautan unduhan kedua versi diaktifkan di akun Anda segera setelah pembelian, sehingga Anda bisa mulai bekerja tanpa menunggu. Bundel ini cocok untuk pekerjaan desain grafis, mock-up, materi pelatihan, dan produksi konten visual.
