Deskripsi

Template Mexico ID Card (Credencial para Votar) ini mencakup 2 versi kartu lengkap sebagai file PSD Photoshop yang dapat diedit sepenuhnya sehingga Anda dapat menyesuaikan setiap nilai sesuai kebutuhan. Semua tata letak dibangun kembali dengan lapisan teks asli yang dapat diedit, sehingga setiap kolom dapat diubah di Adobe Photoshop atau editor web gratis Photopea tanpa merusak desain aslinya.

Produk ini hadir dengan 2 versi berbeda dari kartu pemilih Meksiko, semuanya dalam satu paket: versi utama (tata letak modern dengan pemegang contoh Trejo Machete Daniel, kunci pemilih QNLGLS74071809H701 dan masa berlaku 2014–2024, termasuk PSD kedua dengan efek pindaian dan folder berisi 6 font) serta versi 1 (tata letak klasik yang dikirim sebagai file PSD depan dan belakang terpisah dengan pemegang contoh Romero Garcia Jose Alejandro dan kunci pemilih RMGRAL80042909H700). Kedua file dikirim tanpa kata sandi apa pun.

Kolom nyata yang akan Anda temukan di kartu-kartu ini

  1. PSD versi utama — depan dan belakang lengkap kartu Instituto Federal Electoral dalam satu file ditambah PSD kedua dengan finishing efek pindaian dan folder font berisi 6 jenis huruf termasuk OCR-B
  2. File PSD versi 1 — kartu pemilih klasik sebagai file depan dan belakang terpisah dengan tajuk resmi, foto hantu dan latar guilloche
  3. Semua kolom pribadi dapat diedit — nombre, domicilio, kunci pemilih (QNLGLS74071809H701 / RMGRAL80042909H700), kode CURP (QULL740718HDFNGS04 / ROGA800429HDFMRL06), tanggal lahir (16/05/1944 dan 29/04/1980), jenis kelamin, estado, municipio, sección, localidad, tahun registrasi, penerbitan 2014 dan masa berlaku 2024
  4. Baris MRZ di belakang sepenuhnya dapat diedit — baris contoh dimulai dengan IDMEX1188324645 dan IDMEX1185928112
  5. Penggantian foto melalui lapisan foto khusus — berbasis smart object pada versi 1 dan susunan foto hantu berlapis pada versi utama
  6. Elemen sisi belakang — kode batang 1D, kode QR, kode 2D PDF, kode contoh C004019, strip tanda tangan dan grafik sidik jari
  7. Tajuk resmi dan branding — Instituto Federal Electoral, México, Registro Federal de Electores dan judul Credencial para Votar dengan lambang negara
  8. Kompatibel penuh dengan Adobe Photoshop dan editor online gratis Photopea

Setelah pembayaran, tautan unduhan kedua versi langsung diaktifkan di akun Anda dan file dikirim tanpa kata sandi apa pun. Template ini cocok untuk pekerjaan desain grafis, mock-up, materi pelatihan dan produksi konten visual.
