제품 설명

이 캄보디아 신분증 PSD 템플릿은 레이어가 유지되는 포토샵 파일 두 개를 하나의 제품으로 묶은 번들입니다. 최신 버전 V2(Cambodia-ID-V2.psd 파일, 1748×2480 픽셀)와 이전 버전 V1(ID Card Khmer.psd 파일, 1500×1000 픽셀)이 포함됩니다. 각 파일은 캄보디아 신분증의 앞면과 뒷면을 재현하며, 사진 스마트 오브젝트, 네이티브 텍스트 레이어, 모든 폰트를 함께 제공하므로 레이어를 병합하지 않고도 Adobe Photoshop이나 Photopea에서 모든 값을 편집할 수 있습니다.

이 번들에 포함된 실제 필드

  1. V2 버전 헤더: KINGDOM OF CAMBODIA 명칭과 크메르어·영어 이중 언어 필드, 카드 번호 행
  2. V2 버전 MRZ 라인: IDKHM0210742545<<< 라인, 8203025M2411200KHM<<< 라인, 소지인 이름 KEUK<<NARIN
  3. V2 버전 신원 블록: 영어 이름 JOHN CITIZEN, 생년월일, 성별, 신장, 캄보디아 Kandal주 출생지, 주소, J. Citizen 서명
  4. V2 버전 사진 그룹: 1748×2480 픽셀 캔버스 안에 Pic on Pic 레이어가 있는 사진 스마트 오브젝트
  5. V2 버전 폰트: Arial Regular, OCR-b_10__bt, SCRIPTIN이 font 폴더에 포함됨
  6. V1 버전: PHILIP PUTMAN 이름과 크메르어 이름, 생년월일 17.03.1988, 서명 스마트 오브젝트
  7. V1 버전(1500×1000): 카드 앞면과 뒷면, 체류 요소와 칩이 배치된 레이아웃
  8. 두 버전 공통: 레이어 병합 없이 Adobe Photoshop과 Photopea에서 완전히 편집 가능한 네이티브 텍스트 레이어

다운로드 링크는 구매 직후 계정에서 활성화되며, 비밀번호 없는 ZIP 파일 두 개(각 아카이브 루트에 PSD 파일)를 받게 됩니다. 이 번들은 신원 확인 목업, UI 디자인, 캄보디아 신분 증명서 교육 자료에 이상적입니다.
