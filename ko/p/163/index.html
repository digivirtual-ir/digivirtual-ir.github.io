이 말레이시아 운전면허증 템플릿은 JPJ(말레이시아 도로교통국)가 발급하는 실제 말레이시아 운전면허증 카드 — LESEN MEMANDU — 를 완전히 레이어화된 두 개의 PSD 파일로 재현합니다. 깨끗한 카드 버전(1171×704 px)과 양면을 종이 위에 보여주는 A4 스캔 스타일 시트(1653×2339 px)입니다. 모든 텍스트 필드는 실제 텍스트 객체이므로 Adobe Photoshop이나 photopea.com에서 원본 레이아웃을 손상하지 않고 모든 값을 편집할 수 있습니다.

이 템플릿에 포함된 실제 필드

  1. 앞면 머리말(말레이어·영어): LESEN MEMANDU / DRIVING LICENCE, 말레이시아 국장과 국기, 하이비스커스 기요셰 배경 위의 MALAYSIA 문구
  2. 카드 소지자: MIRAC DUMAN ARSLAN — 스마트 오브젝트 레이어의 인물 사진. 더블클릭하여 원하는 사진을 넣고 설명서대로 노출/밝기를 조정하세요
  3. Warganegara / 국적: MALAYSIA, No. Pengenalan / 신원번호 820615071483
  4. Kelas / 클래스: B B2 C D — B는 500cc 초과 오토바이, B2는 250cc 이하, C는 삼륜차, D는 3500kg 이하 승용차
  5. Tempoh / 유효기간: 21/09/2020 - 20/09/2025
  6. Alamat / 주소: BLOCK 10-2-5 JALAN 2, TAMAN SETAPAK INDAH JAYA, 53300 KUALA LUMPUR, W. PERSEKUTUAN(KL)
  7. 뒷면: A부터 M까지 모든 면허 클래스와 중량 제한을 나열한 JPJL5 클래스 적용표, 일련번호 18073928, 코드 820615 U6PVqjSe, Ketua Pengarah Pengangkutan Jalan 서명 블록
  8. 패키지 구성: DL-Malaysia-V2.psd(깨끗한 카드) + DL-Malaysia-V2-Scan.psd(A4 스캔 시트), 4개 폰트(Arial LatArm, OCR-B 10 BT, Arial Rounded MT Bold, Arial Regular), 사진 소재 PNG — 비밀번호 없음
