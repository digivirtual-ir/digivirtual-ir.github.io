제품 설명

이 이탈리아 체류허가증 템플릿 폰트는 이탈리아 페르메소 디 소조르노(체류허가증) 카드의 PSD 템플릿을 편집할 때 쓰이는 카드 서체입니다. 다운로드는 깔끔한 TTF 파일 하나 — 설치하고, PS/PSD 카드 템플릿을 열고, 필드를 수정하고, 사진을 교체하면 됩니다. 원본 템플릿 페이지가 안내하는 워크플로(다운로드, 폰트 설치, 필드 수정, 사진 교체) 그대로입니다.

이 폰트 패키지에 포함된 것

  1. TTF 파일 하나, Italy-Residence-Permit-Template-Font.ttf, 311,636바이트, 보호 없이 전달되어 바로 설치 가능
  2. 폰트 패밀리 이름 "Arial", PostScript 이름 ArialMT — 체류허가증 필드 타이포그래피에 맞는 Arial 메트릭 카드 폰트
  3. 카드 필드에 쓰이는 라틴 문자, 숫자, 통화 기호, 문장부호를 포괄하는 1320글리프
  4. Windows 설치: TTF를 더블클릭하고 설치 누르기, macOS: Font Book에서 열어 설치
  5. 워크플로 1단계: 폰트를 설치해 체류허가증의 모든 필드가 올바른 서체로 표시되도록 하기
  6. 2단계: PS/PSD 템플릿을 열고 필드 수정 — 성, 이름, 생년월일 정보, 허가 번호, 날짜
  7. 3단계: 사진 레이어를 자신의 이미지로 교체하고 완성된 카드 목업을 내보내기
  8. Photoshop과 Photopea 같은 무료 브라우저 에디터에서 작동, 라이선스 알림도 파일 내 워터마크도 없음

다운로드 링크는 구매 직후 계정에서 활성화됩니다. 파일이 평범한 TTF이므로 어떤 디자인 스택에도 바로 들어갑니다 — 카드 목업, KYC 플로 데모, 온보딩 화면, 교육 자료, 이탈리아 체류허가증의 진짜 look이 필요한 UI 샘플에 딱입니다.
