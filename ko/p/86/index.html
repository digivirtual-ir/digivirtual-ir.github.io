제품 설명

이 멕시코 ID 카드 템플릿(Credencial para Votar)은 완전 편집 가능한 Photoshop PSD 파일 형태의 2가지 완성 카드 버전을 포함하고 있어 모든 값을 필요에 맞게 사용자 지정할 수 있습니다. 모든 레이아웃은 실제 편집 가능한 텍스트 레이어로 재구축되어 있으므로 Adobe Photoshop 또는 무료 웹 에디터 Photopea에서 원본 디자인을 손상하지 않고 모든 필드를 변경할 수 있습니다.

이 제품은 멕시코 유권자 카드의 2가지 서로 다른 버전을 하나의 패키지로 제공합니다: 메인 버전(샘플 소지자 Trejo Machete Daniel, 유권자 키 QNLGLS74071809H701, 유효기간 2014~2024를 갖춘 모던 레이아웃으로, 스캔 효과가 적용된 두 번째 PSD와 6종 폰트 폴더 포함)과 버전 1(샘플 소지자 Romero Garcia Jose Alejandro, 유권자 키 RMGRAL80042909H700을 갖춘 클래식 레이아웃으로, 앞면과 뒷면이 별도의 PSD로 제공). 두 파일 모두 비밀번호 없이 전달됩니다.
