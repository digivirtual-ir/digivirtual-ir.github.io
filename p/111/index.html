Description

Complete card mockup bundle with six versions (V1 to V6) of the photo-realistic ID card / driver licence mockup scene. Import the card you made with any PSD template, and the mockup automatically handles edges, lighting and shadows so the result looks like a real photograph — no manual retouching needed. Backgrounds are fully editable in every version.

How to use

  1. Open the version you want (V1–V6) in Adobe Photoshop — each ships as one large-format PSB file.
  2. Double-click the smart object layer in the Layers panel.
  3. Import your card / licence photo made with any PSD template and click Save.
  4. Adjust size and position if needed; the mockup auto-maps edges and lighting.
  5. In versions V3 to V6 you can also replace the background photo with one click.
  6. Export the final JPEG/PNG and the realistic photo is ready.
