Description

This USA Hawaii driver license PSD template bundle collects three layered Photoshop files in one product: the new V3 edition (with a normal and a scan-style artboard), the V2 edition and the large-format print edition. Every file reproduces both sides of the Hawaii Driver License — the rainbow-holo front and the barcode back — including the „edit text here“ layer group, photo smart objects and all fonts, so every value can be changed in Adobe Photoshop or Photopea without flattening anything.

Authentic fields contained in this set

  1. Authentic card face: the Hawaii / DRIVER LICENSE / USA header with the state flag box, the island-chain artwork, the rainbow gradient background and the AHCD / DONOR marks in the lower right
  2. V3 identity block: Last SAMPLE, First, M TINA, A, street 123 ANYSTREET, city line ANYCITY, AA 00000 and the license number DL# H00000000
  3. V3 data rows: DOB 02/21/1984, Issue 02/17/2010, expiration 02/21/2018, sex M, height 5-02, weight 120 and eye color BRO
  4. Class and back side: 9. Class 3, 12. Restrictions A, 5a. Endorsements NONE, the CORRECTIVE LENSES line, the 2D barcode 12345678 and the GVWR paragraphs covering passenger vehicles, buses and trucks
  5. Signature area with the handwritten signature layer, a scan-style signature artboard and a Sign fonts folder containing Historia, Halimun, Youthness and Southampton
  6. V2 edition (1183×1183): DL# H98520214, name RACHEL DAVIS, birth date 02/21/1991, expiration 02/21/2024 and four selectable background variants in the SELECT BACKGROUND group
  7. Print edition (2025×1275): numbered fields 4a. Iss, 9. Cl, 12. Re, 16. Ht, 17. Wt and 18. Eye with the sample LOW MICHELLE, JUO-MEI, address 3380 LIKINI ST, expiration 07/21/2018 and the repeating Aloha State strip on the back
  8. Photo smart objects (asia-man placeholders) in every file, native text layers for all values and the print-edition fonts arial, arial bold and FG Rebecca Script packed in the archives
