Description

This USA Texas ID card PSD template is a layered Photoshop file that reproduces the American IDENTIFICATION CARD of the state of Texas in its LIMITED TERM version, with two artboards: a combined front and back layout plus a fully editable card back. All texts are native Photoshop layers, the photo is a smart object that can be swapped by double-click, and the fonts folder is included, so every value can be edited in Adobe Photoshop or Photopea without breaking the original design.

Authentic fields contained in this template

  1. Card face: the Texas USA logo with the state flag, the LIMITED TERM header, the star security pattern, the state map, the DONOR heart and the director line in a signature script
  2. Identity block: surname CITIZEN, given name JOHN, card number 4d. ID 00000000, the main photo and a small ghost photo
  3. Date rows: 3. DOB 00/00/0000, 4a. Iss 00/00/0000, 4b. Exp 00/00/0000 and REV: 00/00/0000 on the back — all editable text fields

  6. Card back: the CLASS: A-Comb veh w/ GVWR 26,001 lbs provided towed veh 10,001 lbs line, REST: NONE, END: NONE, the eleven-digit number and the vertical barcode
  7. Back details: the TEXAS ROADSIDE ASSISTANCE: 1-800-525-5555 band, the Directive to physician, Emergency Contact # and Allergic reaction to drugs lines and the DOB line beside the barcode
  8. Extra touches: the John Citizen signature with a second signature layer, the COMMUNICATION IMPEDIMENT, DISABLED VETERAN and MARINE CORPS banners, and the Fonts folder with bahnschrift, DIN Mittelschrift, D432, Asem Kandis, Gatteway Signature and the Sign fonts set
