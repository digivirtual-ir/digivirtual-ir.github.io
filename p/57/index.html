Description

This template faithfully reconstructs a utility bill issued by the Borough of Quakertown in Bucks County, Pennsylvania (USA) — the document the borough's utility department sends to residents for water, sewer, electric and trash services. The package contains both a PDF and an editable Microsoft Word (DOCX) version of the bill, so you can work in whichever editor you prefer: every text, amount and date is a real, fully editable text object and the original layout stays intact.

  1. Official “Borough of Quakertown Utility Bill” letterhead with issue date 04/01/2021, due date 04/30/2021 and page numbering

  3. Service summary grid for WATER, SEWER, ELECTRIC and SOLID WASTE with rows for water, debt service, late fees, misc, demand, sales tax and trash & recycling, each column totalled
