Description

The Poland driving licence template (Prawo jazdy) is provided as a fully editable, layered Adobe Photoshop PSD file in high quality so you can easily customize it for yourself. The design mirrors the Polish driving licence card and covers both sides of the card — front and back — with a complete, true-to-life layout. All layers are named and organized, so editing texts, dates, photo and signature is straightforward.

This file comes in two versions: Version V2 with the new card design (front and back) and Version V1 — the older print edition of this document, which also offers a photo mode once you enable the «Rogi karty» layer. After completing your purchase, both versions together with the required fonts will be available in the download section of your account.

What will you see inside this file?

  • The «PRAWO JAZDY / RZECZPOSPOLITA POLSKA» header with the EU flag and the PL code
  • The photo area and the signature box (field 7)
  • Surname and given names (field 1) and the date and place of birth (field 3, sample: Płońsk)
  • Issue date (4a), expiry date (4b), issuing authority (4c — Starosta) and the PESEL national number (4d)
  • Document number (field 5) and the administrative number with barcode (field 13)
  • The category table (fields 9–12): AM, A1, A2, B, B1, C, C1, D, D1, BE, CE, C1E, DE, D1E and T with validity dates
  • The round red seal, the guilloche security-style background and the fine card pattern
  • A layered PSD file of about 50 MB plus 8 bundled fonts (including Arial, Segoe UI and Southampton)

This template suits graphic designers, mockup and demo projects, layout practice and educational document-design assignments, letting you start from a professional sample instead of building the artwork from zero.
