Description

The Austria ID card template is provided as a fully editable, high-quality PSD file so you can easily customize it for yourself. The design mirrors the Austrian ID card and covers both sides of the card — front and back — with a complete, true-to-life layout. All layers are named and organized, so editing texts, dates, photo and signature is straightforward.

What will you see inside this file?

  • The «PERSONALAUSWEIS / REPUBLIK ÖSTERREICH» header with the EU flag and the AT code
  • The photo area and the signature box (field 7)
  • Surname and given names (field 1) and the date and place of birth (field 3, sample: Wien)

  • The data fields table (fields 9–12): AM, A1, A2, B, B1, C, C1, D, D1, BE, CE, C1E, DE, D1E and T with validity dates
  • The round red seal, the guilloche security-style background and the fine card pattern
