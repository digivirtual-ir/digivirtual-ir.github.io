Description

Put a realistic Nepali driver card in your design portfolio with the Nepal Driving License (Hand) PSD Template. The PSD reproduces the front side of the driving licence format issued by the Government of Nepal (सवारी चालक अनुमतिपत्र) with its bilingual header, chip graphic and guilloche security background, exactly as shown in the hand-held preview. The package contains 1 fully editable Photoshop (PSD) file — open it in Adobe Photoshop, pick the Type tool and change every name, number and date on its own layer in seconds; note that this template includes the front side only and the address field is only partially editable.
