Beskrivning

Denna mall för thailändskt körkort återskapar kortet „Private Motorcycle Driving Licence (Temporary)“ från Konungariket Thailand som en lagrad PSD-fil på 2480×3425 px. Fram- och baksidan finns i två separata grupper, och varje etikett, namn och datum ligger på ett riktigt Photoshop-textlager, så att du kan byta ut alla platshållaruppgifter utan att förstöra kortets ursprungliga design.

Autentiska element i denna fil

  1. Framsidans huvud: thailändsk flagga och den kungliga Garuda-emblemen med raderna „ประเทศไทย / Kingdom of Thailand“ och „ใบอนุญาตขับรถยานยนต์ส่วนบุคคล / Private Motorcycle Driving Licence (Temporary)“
  2. Tvåspråkiga fält på framsidan: „No. 00000000“, „วันออกบัตร / Issue Date 0 January 0000“, „วันสิ้นอายุ / Expiry Date“ samt de thailändska månadsnamnen มกราคม och เมษายน
  3. Namnblock: „ชื่อ / Name“ med platshållarnamnet JOHN CITIZEN WILLIAMS och en fotoram redo att bytas ut
  4. Identitetsrad: „เลขประจำตัวประชาชน / ID No. A0000000“ och „วันเกิด / Birth Date 0 April 0000“
  5. Det nedre blå bandet: „นายทะเบียนจังหวัด ภูเก็ต” — provinsregistrator för Phuket med ett dekorativt cirkelmönster
  6. Baksidan: kortnummer „00 00 0000 0000”, svart magnetrand, QR-kod och en motorcykelikon
  7. Adressblock: „ที่อยู่ / Address” med texten 000/00 Karon, Muang Phuket, Phuket och den thailändska versionen โคกโตนด ต.กะรน อ.เมือง จ.ภูเก็ต
  8. Signaturfält: signaturen (กานดา สันติภัทรานนท์) ovanför „นายทะเบียน / Authority”
