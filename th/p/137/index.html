คำอธิบาย

แม่แบบใบขับขี่ประเทศไทยนี้สร้างการ์ด „Private Motorcycle Driving Licence (Temporary)“ ของราชอาณาจักรไทยขึ้นใหม่ในรูปแบบไฟล์ PSD แบบเลเยอร์ขนาด 2480×3425 px ด้านหน้าและด้านหลังถูกเก็บไว้ในสองกลุ่มแยกกัน และป้ายกำกับ ชื่อ วันที่ทุกรายการอยู่บนเลเยอร์ข้อความจริงของ Photoshop คุณจึงเปลี่ยนข้อมูลตัวแทนทั้งหมดได้โดยไม่ทำลายดีไซน์ดั้งเดิมของการ์ด

องค์ประกอบจริงที่อยู่ในไฟล์นี้

  1. ส่วนหัวด้านหน้า: ธงชาติไทยและตราครุฑพ่าห์พร้อมบรรทัด „ประเทศไทย / Kingdom of Thailand“ และ „ใบอนุญาตขับรถยานยนต์ส่วนบุคคล / Private Motorcycle Driving Licence (Temporary)“
  2. ช่องข้อมูลสองภาษาด้านหน้า: „No. 00000000“, „วันออกบัตร / Issue Date 0 January 0000“, „วันสิ้นอายุ / Expiry Date“ และชื่อเดือนไทย มกราคม และ เมษายน
  3. บล็อกชื่อ: „ชื่อ / Name“ พร้อมชื่อตัวแทน JOHN CITIZEN WILLIAMS และกรอบรูปที่พร้อมเปลี่ยน
  4. บรรทัดข้อมูลตัวตน: „เลขประจำตัวประชาชน / ID No. A0000000“ และ „วันเกิด / Birth Date 0 April 0000“
  5. แถบสีน้ำเงินด้านล่าง: „นายทะเบียนจังหวัด ภูเก็ต“ พร้อมลวดลายวงกลมตกแต่ง
  6. ด้านหลัง: เลขที่ใบอนุญาต „00 00 0000 0000“ แถบแม่เหล็กสีดำ รหัส QR และไอคอนมอเตอร์ไซค์
  7. บล็อกที่อยู่: „ที่อยู่ / Address“ ข้อความ 000/00 Karon, Muang Phuket, Phuket และเวอร์ชันภาษาไทย โคกโตนด ต.กะรน อ.เมือง จ.ภูเก็ต
  8. ช่องลายเซ็น: ลายเซ็น (กานดา สันติภัทรานนท์) เหนือข้อความ „นายทะเบียน / Authority“

ลิงก์ดาวน์โหลดจะเปิดใช้งานในบัญชีของคุณทันทีหลังซื้อ ไฟล์มาในรูปแบบ ZIP ไม่มีรหัสผ่าน ประกอบด้วย PSD แบบเลเยอร์ (2480×3425 px) พร้อมโฟลเดอร์ฟอนต์ที่มี Arial (ปกติและตัวหนา) และ Tahoma
