Paglalarawan

Ang bundle ng template ng pasaporte ng Moldova na ito ay naglalaman ng dalawang PSD file sa iisang produkto: ang bagong bersyon (V2) at ang lumang bersyon ng travel document. Parehong file ay ganap na naka-layer, kaya ang bawat teksto ay maia-edit na layer sa Adobe Photoshop o Photopea, at ang litrato ay inilalagay sa pamamagitan ng smart object nang hindi ginagambala ang mga anino at pagkahulog ng liwanag.
