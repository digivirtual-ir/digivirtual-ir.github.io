Paglalarawan

Ang bundle ng template ng pasaporte ng Russia na ito ay nagbubuklod ng dalawang kumpletong bersyon sa isang post: ang bagong henerasyong pasaporte ng Russian Federation (V3) at ang pasaporte sa lumang format (V2), parehong bilang ganap na na-edit na mga PSD file. Ang V3 file ay 1275×1750 px habang ang V2 file ay 1650×2154 px; ang lahat ng teksto ay nakalagay sa hiwalay na text layer, ang mga larawan ay inilalagay sa pamamagitan ng smart object, at lahat ng font na ginamit ay kasama.

Mga tunay na detalye na nakapaloob sa bundle na ito

  1. Biographic data page ng V3 (bagong format): apelyido GERMANOVICH / Германович, pangalan ДОБРЫНИН ОНУФРИ / DOBRYNIN, kasarian M/M, petsa ng kapanganakan 21.12.1921, lugar ng kapanganakan ЕКАТЕРИНБУРГ / RUSSIA, numero ng pasaporte 70 2893282, inisyu ng ФМС 25011 noong 05.05.2019, wasto hanggang 05.05.2029
  2. MRZ block ng V3, parehong linya: P<RUSNIKULIN<<YURI at 7028932827RUS2112213M2905059<<<<<<<<<<04 — bawat karakter ay nasa sarili nitong na-edit na text layer
  3. Angstruktura ng V3 file: pangunahing larawan at ghost photo sa magkahiwalay na smart object, dalawang na-scan na signature layer, mga hologram na elemento (emblem na РОССИЙСКАЯ ФЕДЕРАЦИЯ, globo ng RUS), guilloche na background at isang scan-effect layer para sa makatotohanang resulta
  4. Data page ng V2 (lumang format): ЗЕРНОВА МАРИЯ ВАСИЛЬЕВНА, kasarian ЖЕН., petsa ng kapanganakan 18.02.1987, lugar ng kapanganakan ГОР. ОШ, РЕСПУБЛИКИ КИРГИЗИIA, serye at numero 380-020

  7. Workflow sa pag-edit: buksan ang alinmang file sa Photoshop o Photopea, i-edit nang direkta ang anumang text layer, palitan ang mga larawan sa pamamagitan ng double-click sa smart object at i-export — 12 font (OCR-B, Helvetica Light, dotted-letters, display-dots at apat na signature font) ang kasama sa V3 file
  8. Paghahatid: dalawang ZIP archive (ang V3 na may fonts folder, hiwalay na V2), instant download pagkatapos ng bayad, walang password sa alinmang archive

Ang two-version pack na ito ay perpekto para sa mga demo ng verification flow, KYC onboarding mockup, graphic design reference, film props at educational material tungkol sa document security features.
