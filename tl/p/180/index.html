Paglalarawan

Ang template ng pasaporte ng Tunisia na ito ay muling ginagawa ang biometric na pasaporte ng Republika ng Tunisia bilang isang buong naka-layer na Photoshop file sa 1789x2391 canvas. Ang bawat elemento ay nasa sariling pinangalanang layer — mga text field, machine-readable zone, guilloche background, barcode strip, pulang selyo at lagda — kaya maaaring muling i-type ang anumang halaga nang hindi ginagambala ang natitirang disenyo.

Mga tunay na detalyeng naka-print sa template ng pasaporte ng Tunisia na ito

  1. Numero ng pasaporte W149535 na may Type P at code of State na TUN sa bilingual na header «REPUBLIC OF TUNISIA / الجمهورية التونسية»
  2. Block ng mayhawak: Apelyido TEMPLATES, mga pangalan ALL PSD, nasyonalidad TUNISIAN, kasarian M
  3. Petsa ng kapanganakan 03-09-1998, lugar ng kapanganakan SFAX/, identity 13002044
  4. Petsa ng pag-iisyu 13-02-2018, petsa ng pag-expire 12-02-2023, nag-isyung ahensya SFAX MEDINA/
  5. Ang machine-readable zone ay muling ginawa linya sa linya: nagsisimula ang unang linya sa P, code na TUN at pangalan ng TEMPLATES / ALL PSD; dinadala ng ikalawang linya ang W149535, birth code 980903, kasarian M, expiry code 230212 at personal na numero 13002044
  6. Ang photo window ay binuo bilang smart object — i-double click ang layer na «main foto», i-paste ang iyong larawan, i-save, at mananatiling buo ang frame, guilloche overlay at alignment
  7. Lahat ng text layer ay hiwa-hiwalang nae-edit sa Adobe Photoshop o sa libreng browser editor na photopea.com — walang na-flatten na pixel at walang password sa file
  8. Barcode strip, pulang selyo at signature block ay naiwan sa hiwalay na mga layer, kasama ang trilingual validity line sa Arabo, Pranses at Ingles

Aktibo agad ang download link sa iyong account pagkatapos ng bayad at naglalaman ang archive ng iisang walang proteksyon na .psd file. Buksan sa Photoshop o photopea.com, muling i-type ang anumang field, palitan ang larawan sa pamamagitan ng smart object, pagkatapos ay i-export sa JPG o PNG o ipasa ang sheet direkta sa pag-print. Ang template na ito ay angkop para sa graphic projects, prop at mockup na gawain, UX presentations, design training at video production.
