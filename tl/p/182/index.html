Paglalarawan

Ang template ng lisensya sa pagmamaneho ng Japan na ito ay muling bumubuo ng Japanese driver license card 運転免許証, bersyon V3, bilang ganap na layered Photoshop file sa 1171x704 canvas, kung saan nasa magkahiwalay na grupo ang harap at likod ng kard. Ang bawat elemento ay nasa sariling layer — ang mga text field, ang photo area, ang berdeng validity band, ang opisyal na pulang selyo, at ang category table — kaya maaari mong muling i-type ang anumang value nang hindi nasisira ang natitirang disenyo.

Mga tunay na detalye na nakapaloob sa Japan driver license template na ito

  1. License number 第 251047191830 号 na naka-print sa harap, kasama ang internal reference number 60183 na katabi mismo ng issue block
  2. Holder block: ang pangalan sa 氏名 ay アルスラン ミラック at ang petsa ng kapanganakan ay 昭和57年6月15日生 — Hunyo 15 ng Showa 57, ibig sabihin 1982
  3. Address line 東京都新宿区北新宿2丁目7-13 — Tokyo, Shinjuku ward, Kita-Shinjuku 2-chome 7-13
  4. Issue data: ang petsa ng 交付 ay nakasulat 令和02年09月21日 kasama ang nag-isyung awtoridad na 東京都公安委員会 (Tokyo Metropolitan Public Safety Commission) at ang bilog na opisyal na pulang selyo
  5. Validity line sa loob ng berdeng band: 令和07年09月20日まで有効 — balido hanggang Setyembre 20 ng Reiwa 7 (2025); category row 普通 para sa mga karaniwang sasakyan, kasama ang petsa ng second at third column na 令和00年00月00日
  6. Ang photo area ay binuo bilang smart object — i-double click ang layer, ilagay ang iyong portrait at i-save; mananatiling buo ang frame, ang overlap ng selyo, at ang alignment
  7. Back-side group: ang 免許の条件等 table na may tatlong binilang na kondisyon sa paningin at assistive device, ang notes area na 備考, ang pirma ミラック アルスラン, at ang petsa ng pirma 2020年09月21日
  8. Lahat ng text layer ay pwedeng i-edit isa-isa sa Adobe Photoshop o sa libreng browser editor na photopea.com — walang na-flat na pixel at walang password kahit saan sa file

Aktibo agad ang download link sa iyong account pagkatapos ng pagbili at naglalaman ang package ng iisang .psd file nang walang password protection. Buksan ito sa Photoshop o photopea.com, muling i-type ang anumang field, palitan ang portrait sa pamamagitan ng smart object, pagkatapos ay i-export sa JPG o PNG, o ipasa agad ang kard sa print.
