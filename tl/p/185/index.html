  3. Linya ng address: 140 RAINIER CT CHULA VISTA, CA 91911
  4. Blok ng pisikal na paglalarawan: taas 5'-11", timbang 185lb, mga matang BLU, buhok na WHT, class C at END NONE

  6. Holographic overlay ng bersyong V4: ang holographic overlay sa itaas ng klasikong California bear, ang DONOR heart at ang IGNITION INTERLOCK mark

  8. Grupo ng likod: barcode block na naka-number 456265254796, Rev 08/29/2017, class C para sa mga sasakyan hanggang 26000 GVWR na walang M/C, ENDORSEMENTS: None at RESTRICTION: None
