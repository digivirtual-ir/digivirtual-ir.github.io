Paglalarawan

Ang kumpletong Cyprus passport template bundle na ito ay naglalaman ng 2 buong na-editable na Photoshop PSD template — ang mas bagong V2 edition at ang mas lumang V1 — lahat sa iisang produkto. Bawat field ay nai-customize sa loob ng ilang segundo at kasama sa package ang lahat ng kailangang fonts.

Ang makikita mo sa loob ng bundle na ito

  1. PSD file ng version V2 — ang pinakabagong disenyo sa malaking high-resolution canvas na 3636×3434 px na may trilingual (Greek/Turkish/English) data page
  2. PSD file ng version V1 — ang mas lumang klasikong disenyo na may parehong trilingual layout, coat-of-arms emblem at stamp group, canvas 1680×2263 px
  3. Fonts folder para sa V2 — 9 typeface kasama ang OCR-B, mga perforation font at handwriting scripts para sa pirma; ang parehong fonts ay angkop din sa V1 file
  4. Lahat ng personal field ay editable — passport number K00233976, type P, country code CYP, apelyido LEE, given name STEVEN, petsa ng kapanganakan 11/02/1994, pag-isyu 14/07/2015, pag-expire 14/07/2025, lugar ng kapanganakan LARNAKA, nasyonalidad CYPRIOT
  5. Ang dalawang linya ng MRZ sa ibaba ay buong na-editable
  6. Pagpapalit ng photo sa pamamagitan ng smart-object layers — nang hindi nasisira ang disenyo
  7. Hiwalay na signature layer at nakalaang smart-object para sa cover photo para sa makatotohanang resulta
  8. Gumagana sa Photoshop at pati na rin sa libreng web editor na Photopea
