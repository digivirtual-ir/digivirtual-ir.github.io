Paglalarawan

Bigyan ng tapat na travel document ang iyong mga design project sa tulong ng Template ng Nepales na Pasaporte PSD. Ginagaya ng PSD file ang biographic data page ng Nepales na pasaporte — kasama ang bilingual नेपाल / NEPAL header, pink na guilloche print, litrato ng may-ari, at machine-readable zone — pati ang observation page na may tatak ng issuing office. Naglalaman ang package ng 1 buong napa-edit na Photoshop (PSD) file kasama ang 6 Calibri-family font; nasa smart-object layer ang litrato — i-double click, isama ang iyong picture, i-save, at a-add-update ang buong page.

Mga detalye ng sample pasaporte

  1. Dokumento: Pasaporte ng Nepal — नेपाल / NEPAL header, type P, country code NPL
  2. Numero ng pasaporte sa sample: 08503398
  3. May-ari: apelyidong TAMANG, mga pangalang SACHIN — nasyonalidad NEPALESE
  4. Kaarawan: 04 OCT 2000 — kasarian M — lugar ng kapanganakan: PALPA
  5. Petsa ng pag-issue: 18 DEC 2015 — petsa ng pag-expire: 17 DEC 2025
  6. Citizenship number: 26811444
  7. Nag-isyung awtoridad: MOFA, DEPARTMENT OF PASSPORT — kasama ang observation page at lagda ng issuing officer
  8. MRZ: two-line machine-readable zone — P<NPLTAMANG<<SACHIN ... / 08503398<8NPL8001254M250212826811444<<<<<<48

Perpekto ang template na ito para sa UI/UX case studies ng travel apps, KYC flow demos, design portfolios, educational materials tungkol sa mga dokumento ng South Asia, at film o theater props na nangangailangan ng kapani-paniwalang pasaporte. I-install muna ang mga kabuang Calibri font, saka i-edit ang bawat pangalan, numero at petsa sa sariling layer, at palitan ang litrato sa pamamagitan ng smart-object layer — sapat na ang basic Photoshop skills.
